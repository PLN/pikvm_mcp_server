# Security

## Reporting a vulnerability

Report a vulnerability privately through GitHub private vulnerability reporting. Open this repository's Security tab and choose "Report a vulnerability".

Do not open a public issue for a vulnerability.

## Supported versions

Only the latest release and the main branch are supported. Releases are container images at `ghcr.io/pln/pikvm_mcp_server` with a matching `vX.Y.Z` git tag. The first stable release is 0.3.0.

## What to include

- What is wrong, and what an attacker can do with it
- The commit, release, or main-branch state you tested
- Steps to reproduce, or a proof of concept if you have one
- The part of the project involved (the server, a workflow, or a dependency)

## Response

PLN will try to acknowledge a report within a few days. Assessment and a fix are best-effort. This is a small personal project. There is no service-level agreement and no guaranteed fix window.
